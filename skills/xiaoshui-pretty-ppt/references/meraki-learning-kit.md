# Meraki Learning Kit / 蓝绘课程册

## Use For

Use this style for course products, children-friendly explainers, creator product demos, workshop pages, learning maps, personal IP introductions, and visual tutorials that should feel lively but not childish.

## Visual Language

- Cream paper background with a subtle grid, thin green borders, and a full-screen presentation canvas.
- Hand-drawn blue identity cues inspired by brand boards, but without directly copying any reference image.
- Forest green main text, bright blue headline accents, blossom pink buttons, butter yellow notes, sky-blue panels, and grass-green bottom strips.
- Replaceable character/IP card, logo system board, color palette board, course-map cards, product/demo cards, and media placeholder panels.
- Controlled rounded corners: friendly, but not overly bubbly. Keep large wrappers and cards structured enough for product and education use.

## Layout Grammar

1. Cover page with large friendly headline, short Chinese explanation, CTA buttons, and a layered product/course-board illustration.
2. Brand board page with logo variations, palette swatches, typography, and doodle marks.
3. Character or creator introduction page with a replaceable IP image area and capability panels.
4. Course map page with five clickable module cards and a detail dock.
5. Product demo page with screenshot/handout/video/card placeholders.
6. Click-reveal teaching page where blocks appear step by step while all blocks remain within one viewport.
7. Replaceable media page with tabs for images, video, IP character, and product shots.
8. Closing page summarizing how the template can be reused.

## Interaction Rules

- Page navigation should stay in the top-right corner so it never covers page content.
- Use vertical scroll snap so each wheel movement lands on a complete slide rather than stopping between pages.
- Keep the bottom arrow for next-page movement.
- Click module cards to switch the detail dock.
- Click the reveal button to show one learning block at a time.
- Use media tabs to switch placeholder guidance.
- Add subtle parallax and hover lifts, but avoid excessive bouncing or low-end cute effects.
- Respect `prefers-reduced-motion`.

## Content Intake Mapping

- Long text: break into module cards, timeline steps, or detail dock copy.
- Images: place in product cards, media preview panels, or character/IP areas.
- Videos: use a video-cover placeholder first; expand to modal or link only when requested.
- Personal IP: place in the character intro page, not as a permanent brand element in the reusable skill.
- Course content: map into problem, method, practice, output, and iteration blocks.

## Avoid

- Do not use a bottom page-number bar that covers CTA buttons or slide content.
- Do not let four learning blocks require extra scrolling inside one slide.
- Do not overuse huge rounded wrappers or make the page look like a low-quality children's poster.
- Do not hard-code the user's personal identity into the reusable template.
