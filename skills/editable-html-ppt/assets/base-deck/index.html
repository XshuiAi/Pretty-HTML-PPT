SUBJECT / PRESENTATION01

Presentation title

用一句清晰判断，概括这份内容的核心。

用两到三句说明来源、对象与这次演示要解决的关键问题。

↗
开场：说明来源、今天的目标，以及听众将带走的核心判断。
READING GUIDE02

Agenda

先给听众一条阅读路径。

  1. 背景与问题
  2. 核心判断
  3. 证据与推演
  4. 行动与结论
说明接下来的叙述顺序。不要逐条念目录，强调逻辑如何递进。
CORE JUDGMENT03

Thesis

让这一页只表达一个可讨论的判断。

用来源中的关键证据或原话解释：为什么这个判断成立，以及它改变了什么理解或选择。

先说结论，再补一条最有力的证据。最后用一句话自然过渡到下一页。
SUPPORTING EVIDENCE04

Three supporting points

01

第一条证据

只保留能直接支持主判断的事实、例子或数据。

02

第二条证据

呈现相互补充而非重复的信息。

03

第三条证据

交代边界、条件或下一步含义。

依次解释三条支撑点；每点都连接回主判断，不扩展成新的主题。
CONCLUSION05

Takeaway

用一句可复述的话，结束这次演示。

基于用户提供的原始内容下一步 / 讨论 / 来源
重申结论，说明下一步行动或邀请讨论。不要在最后一页新增重要信息。
