# 可编辑 PPTX 交付说明

## 两种导出

### 高保真 PPTX

每页为一张高分辨率图片，适用于投影、归档、跨设备播放和复杂视觉稿。文字、特殊字体、线稿与图标不受 PowerPoint 字体回退影响；页面内对象不可逐一编辑。

### 可编辑文本 PPTX

每页仍保留同一张视觉背景，但正文和标题等主要内容改由 PowerPoint 原生文本框覆盖。用户可以编辑这些文本框；图片、特殊字体标题、图标、曲线与装饰保持背景图。

## 字体策略

浏览器和 PowerPoint 的换行与字体替代规则不同，因此不承诺逐字级像素一致。优先选择以下策略：

1. 将品牌字、书法字、图标字和复杂排版留在背景图。
2. 正文使用交付设备已安装的跨平台字体，例如 `Noto Sans CJK SC` 或 `Source Han Sans SC`；交付前确认收件人设备安装该字体。
3. 导出时把字号、位置、宽高、行高和对齐作为文本框的显式属性写入，不依赖 PowerPoint 自动推断。
4. 为正文框预留轻微的高度和宽度余量，降低不同系统换行溢出的风险。

## 编辑范围

可编辑文本只覆盖语义明确、面积足够的主内容：`h1`–`h3`、`p`、`li`、引用、表格单元、定义列表及图注。演讲稿、工具栏、页码与微型导航元素默认不转成文本框。

## 图层与结构线

- 图层选中框仅用于显示；框内点击必须穿透到真实文本、图标或媒体。移动与缩放只由外框边缘热区触发。
- 对独立图形、伪元素和独立线条，直接保存其视觉图层变换。
- 对“容器 `border` 充当横线/竖线，但容器还包裹可编辑正文或图标”的场景，创建虚拟独立线条层。移动该线时只替换对应边框视觉，绝不能平移容器或带动内部内容。
- 虚拟线条层必须在浏览器本地恢复、高保真 PPTX、可编辑文本 PPTX 和导出 HTML 中保持同一视觉位置；重置时应恢复原始边框。

## 撤销与恢复

编辑工具栏中的 ↶ 和 ↷ 用于撤销与恢复已完成的页面级操作。历史记录在当前浏览器会话中最多保存 50 步，覆盖文字、字号、行距、媒体替换、插入图片及视觉图层变换；刷新页面后不延续历史，但已保存的编辑结果仍保留。光标正在文字框内时，优先使用浏览器原生的文字撤销。
